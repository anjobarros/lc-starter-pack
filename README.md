# lc-starter-pack

Local-first Astro marketing starter shaped by Second Brain conventions (Atomic Design, Section/Container layout, typed navigation, content collections).

## Commands

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start local dev server (`localhost:4321`) |
| `npm run build` | Build production site to `./dist/` |
| `npm run preview` | Preview the production build |

Requires Node `>= 22.23.4`.

## Start here

- `/docs` — how the starter was built and how to use it
- `/brandkit` — live atom and molecule catalog
